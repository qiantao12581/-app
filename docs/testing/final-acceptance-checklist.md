# iPhone 最终验收清单

建议安装新版 IPA 后按顺序检查。覆盖安装旧版，不要先卸载。

## 基础记录

- [ ] 首次打开可看到“今日 / 添加 / 历史”三个标签。
- [ ] 在“今日”设置每日碳水、蛋白质和脂肪目标，三项都显示一位小数。
- [ ] “添加 > 食物”搜索“米饭”，选择“熟米饭”。
- [ ] 输入 150 克后显示约 174.0 千卡、38.9 克碳水、3.9 克蛋白质和 0.5 克脂肪。
- [ ] 保存后今日总量立即更新；强制退出再打开，记录仍存在。
- [ ] 对今日记录左滑删除，汇总和剩余量立即重算。
- [ ] 空名称、0 或负数重量、负数营养值均显示中文错误且不清空当前输入。

## 照片和历史

- [ ] 可从相册选择图片并看到预览。
- [ ] 相机按钮可请求权限并拍照；拒绝权限或相机不可用时不会导致 App 崩溃。
- [ ] 页面明确显示“模拟识别，请手动确认”，进入下一页后可修改名称、重量和营养数据。
- [ ] 照片保存的记录可在今日与历史中看到。
- [ ] 历史页按日期倒序显示每天的热量和三大营养素，点击日期可看当天食物。

## 减脂与建议

- [ ] 个人资料可保存性别、生日、身高和日常活动类型。
- [ ] 添加体重后，今日页显示估算基础代谢和日常基础消耗。
- [ ] 添加运动后，今日运动消耗和总消耗增加，专项运动没有重复乘活动系数。
- [ ] 热量缺口为正时显示缺口，为负时显示盈余。
- [ ] 可设置每月 3%、4% 或 5% 的减重速度以及目标体重。
- [ ] 自动模式显示预计完成日期和倒计时；手动模式可指定未来日期。
- [ ] 只记录早餐时，今日页给出午餐、晚餐和加餐建议。
- [ ] 再记录午餐后，建议更新为晚餐和加餐。
- [ ] 三大营养素全部达到目标后，显示无需额外加餐。

## 更新与数据

- [ ] 使用相同 Bundle ID 覆盖安装新版后，旧食物记录和目标仍存在。
- [ ] TrollStore 中 App 的 Bundle ID 为 `com.qiantao12581.NutritionTracker`。
- [ ] App 在 iPhone 14 Pro / iOS 16.5.1 上可正常启动。
