# 营养记录（iOS 16）

面向中文用户的原生 iPhone 食物营养与减脂记录 App，使用 Swift、SwiftUI 和 Core Data，无第三方依赖。最低支持 iOS 16.0，可在 iPhone 14 Pro / iOS 16.5.1 上通过 TrollStore 安装。

## 已实现功能

- 内置 150 条经过来源审计的食物，支持按名称、别名、品牌和标签搜索，并显示品牌、官方规格、来源与营养基准。
- 份量模型支持克、毫升和官方单份三种换算基准，以及“克 / 盒 / 个 / 份”等食物份量名称；切换兼容份量时保持实际用量和营养不变，界面按一位小数显示本次实际摄入。
- 支持创建、搜索、编辑、持久化和删除“我的食物”；手动记录仍可填写每 100 克营养并自动换算。
- 相机拍照或相册选择图片；第一版使用明确标注的模拟识别结果，保存前必须手动确认。
- Core Data 本机持久化食物、原始数量/份量、已知营养字段和自定义食物；支持今日汇总、滑动删除、按日期历史与当天详情。
- 自定义每日碳水、蛋白质和脂肪目标，分别显示还需或超出量。
- 根据已记录餐次和剩余三大营养素，离线生成午餐、晚餐和加餐建议；建议使用食物默认的“克 / 个 / 盒 / 毫升 / 官方整份”单位和分类缩略图。
- 点击建议可修改数量与单位、同类别或跨类别替换食物、添加/删除食物，并实时查看整餐营养及吃完后当天“还差 / 将超出”的三大营养素。确认后整餐只执行一次 Core Data 保存，任一项目或保存失败都会整餐回滚。
- 个人资料、Mifflin–St Jeor 基础代谢、四档非锻炼活动系数和自定义系数。
- 手动记录运动主动消耗，计算预计总消耗、热量缺口或盈余。
- 体重记录、每月 3%–5% 复合减重目标、自动/手动目标日期、进度和倒计时。
- Tab Bar 使用不透明系统背景和分隔线；食物、运动、体重表单使用安全区内全宽底部保存控件，避免被 Tab Bar 或键盘遮挡。
- GitHub Actions 使用最新版稳定 Xcode 自动测试并生成无签名 TrollStore IPA。

## 食物目录与官方数据口径

- 发布目录固定为 150 条：115 条中国疾控中心营养与健康所通用食物、20 条中国大陆品牌乳制品、15 条麦当劳中国菜单食物、0 条肯德基中国食物。肯德基当前没有可核验的中国大陆官方营养来源，因此不收录。
- 通用食物优先使用中国疾控中心来源；品牌食物记录中国大陆官网或官方包装/菜单的来源名称、链接、核验日期和精确规格。完整逐条清单见 [食物目录来源清单](docs/data/food-catalog-sources.md)。
- 不使用 AI 推算、第三方营养表或海外同名产品数据补齐官方缺项。官方没有公布的热量或三大营养素保留为空，并明确显示“暂无官方数据”。
- 数量必须为正且有限；是否允许小数由具体份量定义，不能使用小数的“个/份”会显示中文错误。克、毫升或官方单份之间只在换算基准兼容时切换，并保留实际基础用量，避免营养数值漂移。
- 搜索和添加界面共用基于 SF Symbols 的分类缩略图、颜色和标签，不复制品牌 Logo 或包装图；缩略图附带食物名称和标签的辅助功能描述。今日/历史的跨页面一致性保留在真机验收清单中检查。
- 当任一记录缺少官方营养字段时，今日和历史仅把已知数值显示为“至少 X.X”的下限；缺少热量时不显示精确热量缺口，缺少三大营养素时暂停自动餐次建议。
- 自定义食物保存在本机 Core Data 中。若别名或份量的序列化内容损坏，App 显示中文错误、禁止覆盖原内容，并允许安全删除该条目。

## 构建与安装

没有 Mac 时，按照 [TrollStore 安装说明](docs/distribution/trollstore-install.md) 使用 GitHub Actions 生成并下载 IPA。覆盖升级时保持相同 Bundle ID；不要先删除旧版，否则本地记录可能一并丢失。

有 Mac 时，可在最新版 Xcode 中直接打开 `NutritionTracker.xcodeproj`，选择 `NutritionTracker` scheme 和 iOS 16 或更高版本的设备/模拟器运行。

## 重要说明

基础代谢、活动消耗、食物营养、热量缺口、减脂日期和餐次组合均为估算，仅用于一般记录与规划，不替代医生或注册营养师的诊断和建议。自动代谢与减脂计算仅面向 18 岁及以上成年人，不适用于孕期、哺乳期或需要临床营养治疗的人群。
